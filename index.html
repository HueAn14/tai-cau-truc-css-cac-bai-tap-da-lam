Báo Cáo Tái Cấu Trúc Mã CSS Sang SASS

Tổng hợp chi tiết các tính năng SASS đã áp dụng vào 4 bài tập giao diện Landing Page.

Tính năng SASS Mục đích sử dụng Ví dụ cụ thể trong dự án
Variables (Biến) Quản lý tập trung toàn bộ màu sắc, kích thước font chữ, khoảng cách, bo góc và bóng đổ. $primary-color: #2563eb, $font-size-h1: 42px, $shadow-md
Nesting (Lồng nhau) Phản ánh trực quan phân cấp cây DOM, giúp mã nguồn gọn gàng và tránh đặt tên class quá dài. .navbar { .logo { ... } .nav-menu { .nav-item { ... } } }
Mixins (Tái sử dụng) Đóng gói các đoạn CSS thường xuyên lặp lại: Flexbox, Grid layout, kiểu dáng nút bấm, hiệu ứng card. @mixin flex-layout, @mixin button-theme, @mixin card-theme
Media Queries Mixin Hỗ trợ responsive mượt mà trên mọi kích cỡ màn hình chỉ bằng một dòng lệnh include. @include respond-to("md") { ... }, @include respond-to("sm")
Kiến trúc SASS 7-1 Tách mã thành các thư mục chuyên biệt: abstracts, base, layout, components. Tổ chức 11 file partials _variables.scss, _header.scss...
